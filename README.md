# WT-4 ASP.NET Core MVC — Доставка еды

Лабораторная работа WT-4. Веб-приложение сервиса доставки еды на ASP.NET Core MVC.

## Репозиторий

https://github.com/ihenimo/wt-lab4-4mvc-savostikova

## Опубликованное приложение

https://wt-lab4-4mvc-savostikova.onrender.com

## Технологии

- ASP.NET Core MVC (.NET 10.0)
- Bootstrap 5
- Razor Views
- Docker
- Render (Web Service)

## Функциональность

- Просмотр меню блюд
- Просмотр подробностей блюда
- Добавление блюда
- Редактирование блюда
- Валидация формы
